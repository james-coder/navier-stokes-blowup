# ns-blowup

A friendly Navier–Stokes library with one flagship: the **Singularity Observatory**.

Explore a new mathematical construction, evaluate its implemented components, and run reproducible numerical checks. The public API also supports periodic 2D/3D simulation, diagnostics, plotting, and differentiable experiments.

**Research preview:** the complete smooth blowup construction is not implemented. The observatory currently evaluates specific components and illustrates similarity geometry. Tested capabilities and unimplemented features are separated in the validation record and roadmap.
